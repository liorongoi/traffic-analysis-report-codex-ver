            Import and capture times
            Import verified JPEG/PNG files. Camera names use DDMMYYYY-HHmm-suffix; parsed capture times are UTC to the minute. Imports create independent copies and leave originals untouched. Filesystem modification times are not capture times.
            Time windows
            Schedules use the mission’s IANA time zone. Start is included and end excluded. An overnight window’s weekday and date belong to its start. No windows means all capture times are eligible.
            Views and regions
            Select image rows before batch reassignment. Each assignment keeps its own revision history. ROI polygons use normalized original-image coordinates; exclusion regions override inclusion regions. Old run results remain saved. A changed ROI can be acknowledged and rerun on the same inputs only while the saved model is available and unchanged.
            Review and export
            Detector boxes and night-light results are proposals, not confirmed vehicles. Human review is required. CSV/XLSX exports are snapshots of the selected run and use new filenames rather than overwriting an earlier export.
            Current capabilities
            Still-image General Traffic and a limited local Video Traffic workflow are available. Video runs produce unconfirmed proposals; operators can review events, play sources, and export clips. CSV/XLSX export and continuous still-image monitoring are available. Plate-crop review and still-image search are available. Continuous video folder monitoring requires an explicit saved policy; production Windows and LAN acceptance remain open.
            Local inference and human review. Night lights are experimental candidates, not confirmed vehicles. Still-image monitoring runs in the backend. Manual light-model fitting uses explicitly reviewed labels; YOLOX is not fine-tuned.
            

            PLATE CROP REVIEW
            Plate crops for approval
            The local detector proposes plate regions and editable OCR text in Latin or Arabic/Persian script. OCR is not validated for your target plates, and Persian digit accuracy is unverified. Compare the chip and source, then separately approve, correct, reject, or mark the text unreadable. Chips are saved in the mission output folder.
