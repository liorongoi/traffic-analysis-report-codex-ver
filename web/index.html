        Operator help

        Import and capture times

        Import verified JPEG/PNG files. Camera names use DDMMYYYY-HHmm-suffix; parsed capture times are UTC to the minute. Imports create independent copies and leave originals untouched. Filesystem modification times are not capture times.

        Time windows

        Schedules use the mission’s IANA time zone. Start is included and end excluded. An overnight window’s weekday and date belong to its start. No windows means all capture times are eligible.

        Views and regions

        Select image rows before batch reassignment. Each assignment keeps its own revision history. ROI polygons use normalized original-image coordinates; exclusion regions override inclusion regions. Old run results remain saved. A changed ROI can be acknowledged and rerun on the same inputs only while the saved model is available and unchanged.

        Review and export

        Detector boxes and night-light results are proposals, not confirmed vehicles. Human review is required. CSV/XLSX exports are snapshots of the selected run and use new filenames rather than overwriting an earlier export.

        Current capabilities

        This build runs still-image General Traffic analysis. Video analysis, license-plate recognition, object-search chat, and production LAN deployment are not implemented.

        Local inference and human review. Night lights are experimental candidates, not confirmed vehicles. Monitoring and training remain unconnected.
