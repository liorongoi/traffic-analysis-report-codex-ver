# Plate localization and local OCR pack

This pack contains a YOLOX-tiny plate-region detector and two local ONNX OCR suggestions. The app saves each detected plate chip, displays both suggestions with confidence, and records chip approval separately from text acceptance, correction, rejection, or unreadable decisions. Neither model output is treated as verified without an operator action.

The primary recognizer is an ONNX conversion of PaddleOCR's official [`arabic_PP-OCRv3_mobile_rec` model](https://huggingface.co/PaddlePaddle/arabic_PP-OCRv3_mobile_rec), using the [documented ONNX conversion](https://huggingface.co/tobiichioriguchi/arabic_PP-OCRv3_mobile_rec_onnx) and the [official Arabic dictionary](https://github.com/PaddlePaddle/PaddleOCR/blob/main/ppocr/utils/dict/arabic_dict.txt). Its 161-character dictionary includes Latin, Arabic/Persian letters, ASCII digits, and Arabic-Indic digits. The second suggestion uses the [`fast-plate-ocr` global CCT v2 model](https://github.com/ankandrew/fast-plate-ocr), trained for Latin-letter plates and including an optional region head. This app currently uses its Latin text output only and does not show it for Iran missions, where Arabic/Persian letters are required. The two models are shown as alternatives; neither model silently replaces the other or determines a plate's country. Windows prefers DirectML with CPU fallback; macOS uses CPU. Model/config hashes, sizes, and source URLs are pinned in `manifest.json`, and operation performs no runtime downloads.

PaddleOCR reports 73.55% exact recognition accuracy on a general Arabic-text benchmark. That is not plate-text accuracy. A smoke comparison on the user-supplied reference charts read several illustrated Lebanese Latin/digit examples accurately with the global model, while its region head misclassified the charts; these stylized images are not real-traffic accuracy evidence. Iranian Persian digit forms and OCR quality for Iran, Lebanon, Israel, and Latvia have not been independently evaluated. Inspect each chip and manually correct or reject suggestions. No vehicle identity lookup is performed.

The detector weights are Apache-2.0. Its publisher notice says some community-contributed training photos were used without consent obtained; source imagery is not redistributed. See `NOTICE` and the per-artifact manifest for provenance.
